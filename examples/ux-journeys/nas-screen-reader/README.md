# Screen reader vs visual: the home NAS backup task

Two context-free probes, one task, run against an app called cronmon on
8 October 2026: "One of your jobs backs up the home NAS. Can you find out
when it last checked in, and how long it's allowed to be late before anyone
gets alerted?"

- `visual/journey-log.md` - a normal probe, looking at the page. About 6 actions.
- `screen-reader/journey-log.md` - a probe that only heard the app, through a
  virtual screen reader. 86 steps, same answer.

These are raw journey logs; there is no compiled report yet. The visual log
mentions screenshots that were left out of this example on purpose for privacy reasons.
